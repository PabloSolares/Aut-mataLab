# AutómataLab — Analizador léxico, sintáctico y autómatas

Aplicación de escritorio desarrollada en Java para analizar lenguajes definidos por el usuario y trabajar con autómatas finitos y autómatas de pila.

## Funcionalidades

- Análisis léxico mediante JFlex.
- Análisis sintáctico mediante Java CUP.
- Construcción de autómatas finitos deterministas.
- Construcción y evaluación de autómatas de pila.
- Validación de cadenas.
- Reportes de tokens y errores.
- Visualización de estructuras mediante Graphviz.
- Interfaz gráfica para crear y analizar archivos `.atm`.

## Tecnologías

- Java
- JFlex
- Java CUP
- Graphviz
- NetBeans
- Programación orientada a objetos

## Instalación

Requisitos:

- Java 8 o superior.
- NetBeans.
- Graphviz.

Abre el proyecto en NetBeans, configura las bibliotecas incluidas y ejecuta la clase principal.
